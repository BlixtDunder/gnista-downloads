# Gnista builds

Every build of [Gnista](https://gnista.sh) that shipped: its disk image, and the signed helpers it copies to
Linux machines over SSH. They are files of the [builds release](https://github.com/BlixtDunder/gnista-downloads/releases/tag/builds).

To get Gnista, go to [gnista.sh/download](https://gnista.sh/download/).
